# Changelog

## 1.1.0
- New **Polestar** tab: the Polestar guide window docks under the tabs too. Its guide keeps running on the other tabs.
- `/rxpdock` now cycles Quests → RestedXP → Polestar.
- The tab bar is as wide as the window it sits on, so the RestedXP guide no longer gets pushed off the screen edge.

## 1.0.0
- First release: Quests | RestedXP tabs on the Questie tracker.
- RestedXP keeps running on both tabs (never hidden, only made invisible and click-through).
- RestedXP V1 and V2 window support.
- Combat safe. No empty slot. Ctrl + drag the tabs to move the dock.
